# Ứng dụng Quản lý Sách (Book Management System)

## Thông tin sinh viên
- **Họ và tên:** Trang Đăng Khoa
- **MSSV:** 235197
- **GitHub Repository:** 235197_TrangDangKhoa

## Mô tả đề tài
Ứng dụng web quản lý danh mục sách toàn diện cho phép người dùng thực hiện các thao tác: xem danh sách, xem chi tiết, thêm mới, cập nhật thông tin, xóa và tìm kiếm sách theo từ khóa.

## Công nghệ sử dụng
- **Backend API:** Node.js, Express.js, Mongoose
- **Frontend Web:** React.js (Vite), Axios
- **Cơ sở dữ liệu:** MongoDB Atlas
- **Đóng gói & Triển khai:** Docker, Docker Hub, Render
